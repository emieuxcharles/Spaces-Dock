# Spaces Dock
Utilitaire natif macOS en français : organisation des applications par écran et bureau virtuel, avec le Dock Apple. Deux profils : MacBook seul ou avec un écran externe. Paquet local Apple Silicon, minimum macOS 26 ; moteur 26 conservé, moteur 27 vérifié sous 27.2. Voir docs/RELEASE.md pour les preuves et limites.

Mode Operate : choix explicites, contrôles système, enregistrement automatique, application volontaire ou automatisation activée. La ligne entière se déplace dans son bureau ; le changement d’écran/bureau passe par un sélecteur dédié. Les défauts doivent être récupérables sans modifier manuellement du JSON.
